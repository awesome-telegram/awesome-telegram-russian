# Weight Goal Bot

Групповой бот с естественным русским интерфейсом для еженедельных целей по снижению веса, фотоотчётов, графиков, напоминаний и 53 достижений. Поддерживает девять языков.

## Основная информация
- **Название:** Weight Goal Bot
- **Тип:** Бот
- **Языки:** Русский, английский, китайский, испанский, португальский, немецкий, французский, японский, индонезийский
- **Telegram:** https://t.me/my_weight_goal_bot
- **Исходный код:** https://github.com/IgorShadurin/weight-telegram-bot
- **Лицензия:** Apache-2.0

## Описание

Поставьте цель по снижению веса в группе, отправляйте фотоотчёты и получайте еженедельные рубежи, графики прогресса, напоминания, шутливую обратную связь и достижения.
